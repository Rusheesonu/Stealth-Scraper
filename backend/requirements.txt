# ── Browser engines ──────────────────────────────────────────────────────
# Three engines, three different bypass strategies. The router picks per
# (vendor_hint, capabilities). See backend/app/engines/__init__.py.
#
# nodriver: patches Chromium at the flag/CDP level to close automation
#   leaks Playwright + stealth-JS can't reach. Passes soft Cloudflare /
#   Turnstile invisible mode out of the box. Needs a real Chrome installed
#   locally (brew install --cask google-chrome). Upper bound pinned because
#   0.45+ shipped a ProtocolException regression (see browser.py retry
#   markers) and 0.50.x changed proxy APIs; treat minor bumps as breaking.
nodriver>=0.48,<0.51
#
# curl_cffi: real-Chrome JA3/JA4 TLS impersonation via curl-impersonate.
#   Beats DataDome / Akamai TLS-fingerprint checks on static HTML at
#   ~200ms per request. No JS execution. 0.x → upper bound pinned.
curl-cffi>=0.7,<1
#
# camoufox: patched Firefox + Playwright async API. The only engine that
#   scores clean on creepjs ("0% like headless" vs nodriver's 31%) and
#   the bypass of choice for Kasada / PerimeterX. ~350MB Firefox binary
#   downloaded on first run to user cache dir. MIT-licensed.
camoufox>=0.4,<1
#
# camoufox uses platformdirs to find its binary cache dir. Transitive
# via fastapi/uvicorn today but declared explicitly so engine init never
# breaks if those drop the transitive dep.
platformdirs>=4.0
